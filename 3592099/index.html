02 / Confirmed defects

Passing package tests did not catch these paths.

F1 · Unsaved preview controls

The content renders; the preview safeguards do not.

On Drupal 11.3.10, the embedded node preview lacks Drupal.behaviors.nodePreviewDestroyLinks and nodePreviewSwitchViewMode. Selecting Teaser leaves the route and rendered template at Full. Activating a frontend link leaves the unsaved preview without a confirmation dialog.

Download videoRender planMeasured milestonesPinned display variant ↗
Reproduction and boundary
  1. Edit a saved node with enabled Full and Teaser Canvas templates. Change its title and choose Preview, not Save.
  2. Select Teaser. Observe the selected option change without form submission; the path remains /node/preview/<uuid>/full.
  3. Activate a link inside the frontend. Observe top-level navigation without a confirmation dialog.

The Cancel/Leave choice could not be exercised because the guard dialog never appeared. This is a failure, not a passing cancel test. Review traced the missing library to the display variant’s attachment handling; no implementation fix was applied.

F2 · Shared draft session

A saved-only tab changes another tab’s editor preview.

Opening a canonical preview changes the shared frontend cookie to previewContext.excludeAutoSave: true. The next editor refresh then renders the saved heading, even while its form retains the newer autosaved value.

1 · Editor tab AForm and iframe both show “AUTOSAVE A — Editor working copy”.
2 · Canonical tab BThe same page correctly shows “SAVED — Canvas overview”. Its session excludes autosaves.
3 · Edit again in AForm shows “AUTOSAVE A2 — New editor change”, but the refreshed iframe shows the saved heading.

Refresh interference is browser-confirmed. Timed renewal and the reverse direction are not runtime-verified; the renewal wait was interrupted by the environment/URL reset.

The editor screenshot is withheld because its chrome contains a private preview hostname. This sequence is a textual account of observed values, not a reconstructed screenshot or a video claim.

F3 · Multilingual first-save preview

A new node has no canonical entity ID yet.

A new unsaved article preview worked with one language. After adding French alongside English, Preview before the first save produced a content API 500. The frontend displayed its “Not found” fallback.

Environment and recording caveats
  • Daytona added duplicate ACAO headers to actual metadata GET responses. A recorded local-only exact-origin exception and warning-header allowlist enabled valid sync; OPTIONS or a readable 401 alone was not treated as success.
  • Preview URLs expired during the session reset. New supplied origins were verified and headers rechecked; existing fixtures were preserved. Origin changes were not reported as MR defects.
  • The documented Next proxy shorthand failed production builds. Review verified it and the working explicit-function alternative were unchanged at the MR base; this is setup context, not an MR finding.
  • Only transport/setup adjustments were made. No implementation defect was fixed to make a demo pass. No workaround is included in this artifact collection.
  • Preliminary video takes were rejected for a duplicate iframe cursor overlay or an incorrect dropdown selection. Final link demonstrations use real keyboard focus and Enter; the form demonstration uses paced typing, smooth pointer movement and scrolling.
  • No private preview hosts, credentials, cookies, signed links or raw traffic dumps are included. Cross-tab renewal, reverse interference and delayed new-tab popup blocking remain unverified.
05 / Reproduction outline

Keep the source values distinguishable.

  1. Use the pinned Canvas source and matching built SDK packages. Configure a Next frontend and verify authenticated component sync.
  2. Create a Canvas page with different saved and autosaved headings; create an article template that reads the node title. Give Full and Teaser templates distinct visible labels.
  3. Create older/current article revisions and a published article with a forward moderated draft. Give its unrelated Canvas autosave a third title.
  4. Exercise the canonical, revision, latest-version and repeated form-preview routes. Do not publish the autosave during these checks.
  5. For F2, keep editor A alive while canonical B opens the same entity, then edit A again.
  6. For F3, establish a new unsaved-node baseline with one language, add a second language, rebuild caches and repeat before first save.
  7. Test separate anonymous, no-preview-permission and read-only-preview accounts. Distinguish route access, token mutation permissions and proxy transport failures.

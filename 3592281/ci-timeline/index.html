What slowed it down

  • Intermittent test failures. Browser tests failed on some runs and passed on others; 5 re-runs followed one. One of these tests fails the same way on the main branch, so it isn’t specific to this change.
  • Job time limits. 7 re-runs followed a job stopped at the 30-minute limit, 3 of them with a test already failing.
  • Outages. The automation sandbox was unavailable for about 47 minutes, and a brief DrupalCode outage stopped one passing run from uploading its results.

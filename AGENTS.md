# Repository conventions

- Store every artifact under `<gitlab-work-item-id>/`. Numeric directory names refer to GitLab work items.
- Expect multiple artifacts and artifact types per work item. Use descriptive filenames; group related files in subdirectories as needed.
- Commit messages: `<type>(<gitlab-work-item-id>): <short description>` (e.g. `docs(3592101): add testing guide`).
